# Sprint 1: 16/03/2026 - 05/04/2026

O projeto baseia-se no desenvolvimento de um sistema de coleta de dados de estações meteorológicas.
Esse sistema permitirá coletar automaticamente os dados ambientais, armazená-los em banco de dados e apresentá-los por meio de dashboards, relatórios e alertas climáticos para o público. Dessa forma, instituições públicas poderão monitorar condições climáticas em tempo real, identificar riscos e apoiar a tomada de decisões relacionadas à gestão ambiental e prevenção de desastres.

Tendo em mente o MVP, a primeira sprint se deu com a elaboração da Arquitetura do Sistema, a Modelagem de Dados e recursos para cadastrar, visualizar, editar e deletar (CRUD) estações, parâmetros, alertas e usuários.

<br>

## 🎯 Objetivos da Sprint
O principal objetivo para essa primeira sprint era desenvolver o CRUD completo das entidades, tanto o front-end quanto o back-end.

_"O sistema deve oferecer operações completas de criação, leitura, atualização e exclusão (CRUD) para estações, parâmetros meteorológicos, alertas e usuários."_
